# Наталья — пространство трансформации

Адаптивная демонстрационная версия сайта по согласованному макету. Не требует сборки и работает на GitHub Pages. Подготовлена интеграция с бесплатной CMS [Pages CMS](https://pagescms.org/).

**Приватность:** демонстрация технически публичная. `robots.txt` и метатег `noindex` лишь просят поисковики не индексировать страницы; исходный код, изображения и опубликованный сайт доступны любому, у кого есть ссылка. Не добавляйте сюда закрытые видео, персональные данные клиентов или пароли.

## Что готово

- Главная страница для компьютера, планшета и телефона.
- Каталог активаций с фильтром по статусу.
- Карточки, подробный просмотр, обложки, даты и длительность.
- Встраивание видео **Yandex Cloud Video** по HTTPS-ссылке на плеер.
- Избранное в браузере (деморежим).
- Мобильная навигация и блок консультации.
- Редактирование текстов, изображений и списка активаций через Pages CMS.

## Опубликовать на GitHub Pages

1. Создайте новый **публичный** репозиторий в GitHub (например, `natalia-space`). Бесплатный GitHub Pages доступен для публичных репозиториев.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `script.js`, `assets/`, `data/`, `.pages.yml`, `.nojekyll`.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем сохраните.
5. Подождите завершения публикации. Ссылка появится в `Settings → Pages` (обычно `https://ИМЯ.github.io/natalia-space/`).

Внутренние ссылки и ресурсы сайта относительные, поэтому проект работает внутри подпапки GitHub Pages.

## Подключить Pages CMS

1. Откройте [app.pagescms.org](https://app.pagescms.org/).
2. Войдите через GitHub и подключите приложение Pages CMS к репозиторию сайта.
3. CMS найдёт файл `.pages.yml` в корне.
4. Наталья сможет редактировать разделы **«Главная страница»** и **«Активации и записи»**.
5. После сохранения Pages CMS создаст коммит в GitHub, а Pages обновит опубликованный сайт.

Важно: для подключения приложения на GitHub нужны соответствующие права. Если у Натальи нет GitHub, предоставьте ей редакторский доступ способом, который поддерживает Pages CMS. Не передавайте пароль от вашего GitHub.

## Добавить активацию

В CMS откройте `Активации и записи`, добавьте новый элемент списка и заполните:

- `id`: уникальный технический идентификатор латиницей, например `new-practice`;
- название, подпись, описание;
- `status`: `current` для актуальной записи или `soon` для анонса;
- обложку, длительность, дату публикации;
- ссылку в `videoUrl` при наличии записи.

Поле `featured` отмечайте у одной главной активации: она будет крупной карточкой и попадёт в нижний блок видео.

## Видеозаписи и безопасность

Яндекс.Диск не предоставляет штатного встраиваемого плеера. Для просмотра на странице используется **Yandex Cloud Video**. В его интерфейсе выберите «Код вставки» и вставьте **значение `src` iframe**, а не весь HTML-код. Проект разрешает iframe с `video.cloud.yandex.net` и `runtime.video.cloud.yandex.net`.

Встроенные ссылки подходят для открытых или демонстрационных видео. Защищённый платный доступ не следует реализовывать на GitHub Pages: нужна отдельная серверная часть с проверкой прав пользователя и приватным хранением оригиналов.

## Текущие ограничения демонстрации

- «Мой кабинет» показывает избранное, которое хранится **только в браузере** и не синхронизируется с аккаунтом.
- Форма записи и оплата не подключены, потому что ещё нет согласованных контактов и платёжного сценария.
- Видеозапись в каталоге не воспроизводится, пока в CMS не добавлена реальная ссылка.
- Интерьерные изображения и герой первого экрана — изображения на основе предоставленного макета, их можно заменить через CMS исходными фотографиями Натальи.
- GitHub Pages не предоставляет серверную CMS, базу пользователей, оплату и конфиденциальное хранение файлов. Для этих задач на следующем этапе понадобится сервер.

## Запустить локально

Откройте терминал в этой папке и выполните:

```bash
python3 -m http.server 8000
```

После этого сайт доступен на `http://localhost:8000/`. При открытии `index.html` как локального файла браузер может заблокировать загрузку JSON, поэтому используйте HTTP-сервер.

## Структура

```text
index.html             Структура страниц
styles.css             Дизайн и мобильная адаптация
script.js              Карточки, фильтры, модальные окна
data/site.json         Тексты главной страницы
data/activations.json  Каталог активаций
assets/                Изображения
.pages.yml             Поля и разделы Pages CMS
```
